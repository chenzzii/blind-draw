# 學生分組與報告日期盲選（AI Hall 許願實作）

這是一款給國中輔導課與一般課堂使用的**單機、免登入**網頁工具，協助教師將學生分組，再讓每組以翻牌盲抽方式決定上台報告的時段。



## 功能

- 貼上名單（每行一名學生或一個座號），按每組人數隨機或依名單順序分組。
- 手動調整各組成員並檢查重複名單。
- 設定報告日期、時段與每場容納的小組數。
- 每組翻開一張卡片抽選報告時段；已使用卡片不重複抽取。
- 匯出 Excel 可開啟的 CSV、列印、備份／還原 JSON。
- 瀏覽器本機儲存；不需要後端、不需要建立學生帳號。

## 使用方式

1. 下載或開啟 `index.html`（建議 Chrome 或 Edge）。
2. 在「學生分組」貼上學生座號或代碼，每行一個，產生分組。
3. 在「報告場次」新增報告日期或時段，設定每場名額。
4. 在「盲選抽籤」選擇小組，讓學生翻開尚未使用的卡片。
5. 在「結果總覽」下載 CSV，或用右上角「備份 JSON」。

也可以按右上角「載入示範資料」先體驗完整流程。

## 在 GitHub Pages 發布

此專案為純 HTML／CSS／JavaScript，沒有外部建置依賴。將檔案放到 GitHub 儲存庫的 `main` 分支，再到 **Settings → Pages → Build and deployment → Deploy from a branch**，選擇 `main` 與 `/(root)`，即可發布靜態網站。

> GitHub Pages 發布後仍是**每位瀏覽器使用者獨立的本機狀態**，不會同步成一份班級抽籤。若要多人協同使用，必須另行設計登入、後端資料庫與同步機制。

## 隱私與公平性提醒

- **建議只輸入學生座號或代碼**，避免將完整姓名或其他個資放在公用電腦。
- 資料保存在瀏覽器 `localStorage`；清除瀏覽器資料或切換設備可能失去紀錄，請抽完立即匯出或備份。
- 卡片以瀏覽器亂數洗牌，避免同一卡片重複抽選；不宣稱提供可供第三方稽核的密碼學級公開公平性驗證。
